# Public Commons Charter

## Mission

Publish reusable infrastructure that makes agentic systems more governable,
inspectable, portable, testable, and locally controllable.

## Governing rule

**Open the rails. Protect the routing intelligence.**

## Public forms

A safe public slice may contain:

1. Interface
2. Schema
3. Validator
4. Synthetic fixture
5. Limited reference implementation
6. Architecture note

## Publication invariant

No artifact becomes public until:

- ownership is reviewed;
- dependencies and licenses are reviewed;
- secret and data scans pass;
- only synthetic fixtures remain;
- public claims match current code and tests;
- a release receipt is completed;
- the founder explicitly approves publication.
