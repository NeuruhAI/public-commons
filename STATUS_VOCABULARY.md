# Status Vocabulary

Every public artifact declares one status:

- Experimental
- Active Alpha
- Active Beta
- Stable
- Maintenance Mode
- Archived
- Reference Only

## Evidence vocabulary

- CANONICAL — governing definition or architecture
- CODE-VERIFIED — code and tests support the claim
- LIVE-VERIFIED — direct runtime evidence supports the claim
- RELEASE QUALIFICATION — built, tested, final acceptance remains
- PROTOTYPE / PARTIAL — bounded implementation exists
- SPEC-ONLY — architecture without adequate implementation proof
- UNKNOWN / CONFLICTED — do not promote
